# viv.me.uk — Personal Website Overhaul

This repo is Viv's personal website, currently hosted on GitHub Pages at **viv.me.uk**.

The site is undergoing a complete redesign: from a legacy Jekyll/Bootstrap site to a modern Astro + Tailwind CSS build with GSAP scroll-driven animations, dark-mode-first design, and a cinematic single-page experience showcasing 25+ years of software engineering.

## Session Workflow

- This project is broken into discrete sessions documented in the project plan
- Each session has a starter prompt — paste it into a new Claude Code conversation
- After completing a session, follow the **Session Completion Checklist** at the end of each prompt
- Name sessions to match the plan (e.g. `/rename Session 0.1 - Website Inspiration`)
- Update the **Progress Log** in the project plan after every session

## Conventions

- UK English throughout (organisation, colour, behaviour)
- Conventional commits (feat:, fix:, docs:, chore:, refactor:)
- Commit messages explain **why**, not **what** — see global CLAUDE.md for examples
